# Grafana-Provisioning

Dieser Ordner enthaelt die automatische Erstkonfiguration von Grafana. Beim Containerstart werden Datenquellen und Dashboard-Anbieter geladen.

Die konkreten Einstellungen liegen in `dashboards` und `datasources`.
