# Grafana

Dieser Ordner enthaelt die Grafana-Konfiguration und die Dashboards fuer die Zeitreihen aus InfluxDB.

Grafana wird ueber Docker Compose gestartet und ist auf Port `3000` erreichbar. Die Dashboard- und Datenquellen-Konfiguration liegt in den Unterordnern `dashboards` und `provisioning`.
