# Mosquitto-Konfiguration

In diesem Ordner liegt die Mosquitto-Konfiguration, insbesondere die Broker-Einstellungen in `mosquitto.conf`.

Aenderungen an der Konfiguration werden nach einem Neustart des Mosquitto-Containers wirksam.
