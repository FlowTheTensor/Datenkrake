# Node-RED-Flows

Dieser Ordner enthaelt die exportierten Node-RED-Flows fuer die Auswahl und Verarbeitung der Anlagenknoten.

Die JSON-Dateien werden vom Node-RED-Container verwendet und koennen ueber die Node-RED-Oberflaeche weiterbearbeitet werden.
