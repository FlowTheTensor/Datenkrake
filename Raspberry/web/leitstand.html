Live-Abrufe funktionieren nur, wenn diese Seite von einem Rechner mit Netzzugriff auf die Agenten geöffnet wird, und wenn die Agenten CORS für diesen Ursprung erlauben. Schlägt ein Abruf fehl, zeigen Cards und Konsole "demo"-Daten bzw. eine Fehlermeldung statt leer zu bleiben.

Chat & Konsole

Verbunden mit lokalem LLM über LM Studio (OpenAI-kompatibel). Endpunkt in ⚙ Einstellungen anpassen.
Erwartet einen laufenden lokalen Server unter LM Studio → "Local Server" → Start. Antworten laufen über einen Systemprompt mit Kontext zum Datenkrake-Agentensystem.
Sendet eine Textnachricht per A2A (JSON-RPC "message/send") an den gewählten Agenten.
Genauer RPC-Pfad kann je nach a2a-sdk-Version abweichen — bei Fehlern zuerst mit curl gegen die Agent Card prüfen.

Architektur

Der Orchestrator-Agent überwacht die Datenkrake und greift bei Bedarf per LAP auf sein eigenes Zusatzgerät zu — nie auf eine Produktionssteuerung. Das YOLO-System ist im Schema als "geplant" markiert, siehe README zur aktuellen Datenlage.
