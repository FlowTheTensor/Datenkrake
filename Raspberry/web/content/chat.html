Chat & Konsole

Verbunden mit lokalem LLM über LM Studio (OpenAI-kompatibel). Endpunkt in ⚙ Einstellungen anpassen.
Erwartet einen laufenden lokalen Server unter LM Studio → "Local Server" → Start. Antworten laufen über einen Systemprompt mit Kontext zum Datenkrake-Agentensystem.
Sendet eine Textnachricht per A2A (JSON-RPC "message/send") an den gewählten Agenten.
Genauer RPC-Pfad kann je nach a2a-sdk-Version abweichen — bei Fehlern zuerst mit curl gegen die Agent Card prüfen.
