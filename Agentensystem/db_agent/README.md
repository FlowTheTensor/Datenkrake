# Datenbank-Agent

Der DB-Agent stellt Telemetriedaten und offene Anomalien ueber eine A2A-Schnittstelle bereit.

## Start

```text
python -m db_agent
```

Der A2A-Server verwendet Port `9999`. Fuer den Datenbankzugriff muessen die `DK_*`-Umgebungsvariablen gesetzt sein.
