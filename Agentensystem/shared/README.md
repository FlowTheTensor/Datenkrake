# Gemeinsame Dienste

Dieser Ordner enthaelt gemeinsam genutzte Komponenten fuer das Agentensystem. `db_service.py` kapselt den Datenbankzugriff fuer Agenten und Poller.

Der Ordner ist eine Bibliothek und besitzt keinen eigenen Startbefehl.
