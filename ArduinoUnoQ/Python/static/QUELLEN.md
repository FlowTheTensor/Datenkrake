# Lokal mitgelieferte Bibliotheken

Flask liefert diesen Ordner unter `/static/` aus. Die Bibliotheken liegen lokal,
damit die Weboberfläche keine Verbindung zu einem CDN aufbaut (DSGVO) und auch
ohne Internet läuft. Lizenztexte stehen in `lizenzen/`.

| Datei | Version | Lizenz |
|---|---|---|
| `chart.umd.min.js` | Chart.js 4.4.1 | MIT |
| `tf.min.js` | TensorFlow.js 4.22.0 | Apache 2.0 |
| `anime.min.js` | anime.js 3.2.1 | MIT |
